This website adapts the personal-page layout and stylesheet from [Jon Barron’s website](https://github.com/jonbarron/jonbarron.github.io).

Research pages adapt [Eliahu Horwitz’s Academic Project Page Template](https://github.com/eliahuhorwitz/Academic-project-page-template), which incorporates parts of [Nerfies](https://nerfies.github.io/). The template and adaptations of its design are shared under [Creative Commons Attribution-ShareAlike 4.0 International](https://creativecommons.org/licenses/by-sa/4.0/).

Modifications include navigation, research selection cards, figure layouts and integration with this website. The template versions are based on the code available on November 17, 2025. [Source versions and license details](https://github.com/seokyung26/seokyung26.github.io/blob/main/TEMPLATE_CREDITS.md).
