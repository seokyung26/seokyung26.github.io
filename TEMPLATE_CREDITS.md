# Template sources

The template baseline is the latest commit available on or before 2025-11-17 (UTC).

- Personal website: Jon Barron, https://github.com/jonbarron/jonbarron.github.io/tree/a2fb8a0055257d5f47571c84cf6234d36a26007e (2025-11-05). Adapted profile and research-list structure; original stylesheet retained in assets/template/jonbarron.css. Upstream README permits personal use.
- Research project pages: Eliahu Horwitz, Academic Project Page Template, https://github.com/eliahuhorwitz/Academic-project-page-template/tree/d38af1ccae1ce82c3404d2820c4c646afd409f81 (2025-09-04). Adapted publication hero, author and affiliation blocks, resource buttons, and figure sections; original Bulma and index styles retained in assets/template. Parts of this template originate from Nerfies (https://nerfies.github.io/).
